There are TWO types of export & import

- Default Export & Import
  -- Export - export default Component;
  -- Import - import Component from ../../abc;

- Named Export & Import (This is used when you need to export more than one component or constants from one file)
  -- Export - export const Component;
  -- Import - import { Component } from ../../abc;
